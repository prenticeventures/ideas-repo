## 5. Topo Map Creator — Settings Guide

> **App URL:** https://topo-map-creator.vercel.app/
> **How it works:** Draws an elevation grid (gridSize × gridSize samples) over your rectangle using Mapbox Terrain-RGB tiles, then renders contour lines using marching squares + Chaikin smoothing.

### Understanding the Three Key Settings

**Contour Interval (meters)** — Controls line density
- Smaller interval = more lines = more dramatic / complex look
- Larger interval = fewer lines = cleaner / more minimal look
- The batch script auto-computes this per location (targets ~20 lines across the full elevation range)
- Flat terrain (small range) automatically gets a fine interval; mountains get a coarser interval

**Grid Resolution (NxN)** — Controls smoothness and detail
- Higher grid = more elevation samples = smoother, more accurate contour lines
- Lower grid = blockier, faster to generate
- The app range is 20×20–200×200 (default 50×50)
- Batch script uses 160×160 for most locations; 120×120 for very large areas
- The app's default (50×50) is too coarse for print quality

**Rectangle / Bounding Box** — Controls zoom level / scale
- Larger area = wider view, terrain looks more "zoomed out"
- Smaller area = tighter zoom, features more prominent
- In the batch script, each location has pre-set N/S/E/W bounds stored in `scripts/locations.ts`
- These match the North / South / East / West coordinate fields shown in the app UI

### How Dynamic Contour Intervals Work

The batch script calculates contour interval automatically from the actual elevation data:

1. Fetch elevation grid for the bounding box
2. Find the min and max elevation values in the grid
3. Compute `rawInterval = (max - min) / 20`
4. Round up to the nearest "nice" value: 5, 10, 15, 20, 25, 30, 40, 50, 75, 100, 125, 150, 200, 250, 500m

This guarantees ~20 lines if you trace a straight vertical path from the lowest to highest point. In practice, steep terrain (canyon walls, mountain faces) shows dense lines, while flat areas (plateaus, valleys) show sparse lines — exactly like a real topo map and the example images.

### Rectangle Aspect Ratio Guide (for manual app use)

To hit the correct canvas aspect ratio, draw your map rectangle so that:
`(lon span × cos(latitude)) / lat span = target ratio`

| Print Size | Target Ratio | At ~36°N (Grand Canyon, Zion) | At ~44°N (Tetons, Glacier) | At ~48°N (Olympic) |
|-----------|-------------|-------------------------------|---------------------------|-------------------|
| 16×20" portrait | 0.80 | lon = lat × 0.99 | lon = lat × 1.13 | lon = lat × 1.20 |
| 18×24" portrait | 0.75 | lon = lat × 0.93 | lon = lat × 1.06 | lon = lat × 1.12 |
| 20×16" landscape | 1.25 | lon = lat × 1.54 | lon = lat × 1.76 | lon = lat × 1.87 |
| 3:2 landscape | 1.50 | lon = lat × 1.85 | lon = lat × 2.11 | lon = lat × 2.24 |
| 1:1 square (coaster) | 1.00 | lon = lat × 1.24 | lon = lat × 1.41 | lon = lat × 1.49 |

## 6. Calibration Checklist (Grand Canyon — First Map)

Use this as your calibration run to dial in the settings:

1. Navigate to Grand Canyon South Rim area (~36.1°N, 112.1°W)
2. Draw rectangle: lat span ≈ 0.30° (~20 mi), lon span ≈ 0.56° (~25 mi) for ~3:2 landscape
3. Line color: `#C4622D` (terracotta), Background: `#FFFFFF`
4. Contour interval: **40m**, Grid resolution: **150×150**
5. Generate → compare to the example image in `images-examples/`
6. Adjust contour interval up (less dense) or down (more dense) to taste
7. When happy, export at **8x PNG** → upload to Printify Product Creator
