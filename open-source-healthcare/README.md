## What the article covers

Krishnan lists areas of open source healthcare he finds interesting, and says the list is not exhaustive. The categories and named projects are:

1. Open source datasets: MIMIC, Stanford AIMI imaging repositories, DeepLesion, gnomAD, OpenNeuro, Synthea synthetic data, Recursion RxRx, Broad Cell Painting Gallery, AlphaFold, Open Targets Platform, government billing datasets including Medicaid claims, and food testing data including PlasticList and OpenLabel.
2. Open source data infrastructure and tooling: data ontologies OMOP, SageRx, and Tuva Health, rails for health information exchanges Metriport, FHIR servers HAPI FHIR, wearable ingestion Open Wearables, claims data Blue Button, MCP connectors including a Josh Mandel EHR to agent repo, EHRs VistA, Medplum, Ottehr, OpenCoreEMR, and OpenEMR, prepackaged analytics scripts PhysioToolkit and Mimilabs, and clinical NLP pipelines cTAKES, medspaCy, scispaCy, and John Snow Labs.
3. Open source AI models and algorithms: MedGemma, Meditron, MONAI, Sophont, and BioMistral.
4. Open source disease measurement: OpenWillis, Kintsugi voice models, and Pfizer Scikit Digital Health.
5. Open source hardware: Loop and openAPS, and open source prosthetics including E-Nable, Open Source Leg, and OpenBionics, plus 3D printed crutch add ons.
6. Closing notes: an open source provider directory as an unsolved need, and Turquoise PATIENTS Framework payment rails.
